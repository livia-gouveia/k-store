## K-Store

A K-Store é uma loja virtual de produtos de K-pop desenvolvida em React como projeto acadêmico.

O projeto foi criado com o objetivo de praticar conceitos fundamentais do desenvolvimento web com React, como criação de componentes, utilização de props, renderização de listas e navegação entre páginas.

## Acesse o projeto
https://k-store-sooty.vercel.app/

## Tecnologias utilizadas

- React
- JavaScript
- CSS
- React Router

## Versões do projeto
### Versão básica

Localizada na pasta `ver-basica`.

Essa versão contém as principais funcionalidades desenvolvidas durante a atividade:

- Página inicial
- Página de produtos
- Página de contato
- Navegação entre páginas com React Router
- Componentes reutilizáveis
- Utilização de props
- Renderização dos produtos com `map()`
- Estilização das páginas com CSS
- Layout responsivo

### Versão com carrinho

Localizada na pasta `ver-carrinho`.

Após a conclusão da versão básica, o projeto foi incrementado com um sistema de carrinho de compras.

Além das funcionalidades anteriores, essa versão possui:

- Adição de produtos ao carrinho
- Alerta ao adicionar um produto
- Contador de itens no cabeçalho
- Página do carrinho
- Controle da quantidade dos produtos
- Botões para aumentar e diminuir a quantidade
- Gerenciamento do carrinho utilizando `useState`

## Produtos

A loja possui um catálogo fictício de álbuns e lightsticks de diferentes artistas de K-pop.

Os produtos são armazenados em uma lista e exibidos dinamicamente por meio do método `map()`, utilizando um componente reutilizável para os cards.

## Interface

A interface da K-Store utiliza uma paleta baseada em azul, roxo e rosa e foi desenvolvida com CSS, incluindo adaptações para diferentes tamanhos de tela.
